================================================================
 IT-ASSET-MGMT — EXTERNAL SECRETS FOR OPENBAO
================================================================
Put these into OpenBao FIRST, before deploying anything.
Engine: KV v2 (bao secrets enable -path=secret kv-v2)
Base path convention: secret/it-asset/<service>

In the cluster, External Secrets Operator (ESO) reads these paths
from OpenBao and syncs them into Kubernetes Secrets, which the
Deployments mount as env vars. Locally, docker-compose reads the
same var NAMES from a gitignored .env file (see .env.example).

Legend:  [WIRED] consumed by code today   [PLANNED] prod-grade, wire later

----------------------------------------------------------------
 1. secret/it-asset/postgres            (shared DB)
----------------------------------------------------------------
  POSTGRES_DB               = itasset            [WIRED]
  POSTGRES_USER             = itasset_app        [WIRED]
  POSTGRES_PASSWORD         = <strong-random>    [WIRED]

----------------------------------------------------------------
 2. secret/it-asset/assetservice       (business service :8080)
----------------------------------------------------------------
  SPRING_DATASOURCE_URL      = jdbc:postgresql://postgres:5432/itasset   [WIRED]
  SPRING_DATASOURCE_USERNAME = itasset_app                               [WIRED]
  SPRING_DATASOURCE_PASSWORD = <same as POSTGRES_PASSWORD>               [WIRED]
  JWT_SECRET                 = <>= 32 bytes, base64/random>              [WIRED]
      # code default is a dev fallback — MUST be overridden in every real env

----------------------------------------------------------------
 3. secret/it-asset/discovery-server   (Eureka :8761)
----------------------------------------------------------------
  EUREKA_DASHBOARD_USERNAME  = eureka-admin       [PLANNED]  # dashboard is open today
  EUREKA_DASHBOARD_PASSWORD  = <strong-random>    [PLANNED]
      # clients that register must send matching EUREKA_CLIENT_USERNAME/PASSWORD

----------------------------------------------------------------
 4. secret/it-asset/config-server      (Spring Cloud Config :8888)
----------------------------------------------------------------
  CONFIG_SERVER_USERNAME     = config-admin       [PLANNED]  # server is open today
  CONFIG_SERVER_PASSWORD     = <strong-random>    [PLANNED]
  ENCRYPT_KEY                = <symmetric key>     [PLANNED]  # enables {cipher} values
  # If/when the native backend is swapped for a private git backend:
  CONFIG_GIT_URI             = git@github.com:...  [PLANNED]
  CONFIG_GIT_USERNAME        = <>                  [PLANNED]
  CONFIG_GIT_TOKEN           = <PAT>               [PLANNED]

================================================================
 QUICK LOAD (OpenBao CLI)
================================================================
  export BAO_ADDR=https://openbao.internal:8200
  bao login

  bao kv put secret/it-asset/postgres \
      POSTGRES_DB=itasset POSTGRES_USER=itasset_app POSTGRES_PASSWORD='...'

  bao kv put secret/it-asset/assetservice \
      SPRING_DATASOURCE_URL='jdbc:postgresql://postgres:5432/itasset' \
      SPRING_DATASOURCE_USERNAME=itasset_app \
      SPRING_DATASOURCE_PASSWORD='...' \
      JWT_SECRET='...'

  bao kv put secret/it-asset/discovery-server \
      EUREKA_DASHBOARD_USERNAME=eureka-admin EUREKA_DASHBOARD_PASSWORD='...'

  bao kv put secret/it-asset/config-server \
      CONFIG_SERVER_USERNAME=config-admin CONFIG_SERVER_PASSWORD='...' ENCRYPT_KEY='...'

Generate strong values:  openssl rand -base64 48
